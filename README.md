#Browser OS: Ein Betriebssystem, das einfach im Browser lebt

Stell dir vor, du brauchst keinen Installer mehr. Kein Setup, kein Warten, kein „Systemvoraussetzungen prüfen“. Du öffnest einen Browser – und hast einen kompletten Desktop vor dir. Mit Fenstern, Apps, einem App-Katalog zum Nachinstallieren. Genau das ist Browser OS.
Was ist Browser OS?

Browser OS ist ein Desktop-Betriebssystem, das komplett in HTML, CSS und JavaScript umgesetzt ist – läuft also überall dort, wo ein Browser läuft. Kein Server im Hintergrund nötig, kein localhost, keine Installation. Es funktioniert sogar direkt von der Festplatte, offline, ganz ohne Internetverbindung.

Ausprobieren kannst du es direkt hier: os.vorne.at

Mehr Hintergrund und Doku gibt’s auf der Info-Seite: www.vorne.at/browser-os
Was kann es schon?

    Ein Fenstermanager mit Desktop-Umgebung, wie man es von klassischen Betriebssystemen kennt
    Ein PDF-Viewer
    Erste Spiele und kleine Tools als eigenständige Apps
    Ein App-Katalog, über den sich weitere Apps direkt nachinstallieren lassen
    Sync zwischen mehreren Geräten – Einstellungen und Apps bleiben auf all deinen Rechnern gleich

#Warum das Ganze?

Die Idee dahinter: möglichst wenig Reibung zwischen „ich will etwas ausprobieren“ und „es läuft“. Kein Account nötig, kein Download, keine Wartezeit. Gerade für Tüftler, Bastler und alle, die gerne mit wenig Aufwand viel experimentieren, ist das ein spannendes Spielfeld – ein System, in dem man einfach mal reinschauen und mitbauen kann, ohne erst tief in Systemarchitektur einsteigen zu müssen.
Open Source, offen für alle

Browser OS steht unter der GPLv3-Lizenz – der Code ist offen einsehbar, veränderbar und wird von der Community weitergetragen. Wer selbst eine App beisteuern möchte, kann das über ein eigenes, bewusst simples App-Manifest-Format tun. Man muss dafür nicht den gesamten Systemkern verstehen – ein bisschen HTML, CSS und JavaScript reicht oft schon.
Mitmachen

Das Projekt steht am Anfang seiner Reise als offenes Community-Projekt – und genau deshalb zählt jede Rückmeldung. Ob du es einfach mal ausprobierst und Bugs meldest, eigene App-Ideen hast, oder gleich mitcoden willst: Browser OS lebt von Leuten, die neugierig sind und mitgestalten wollen.
